  # 🐎 СКАЧКИ·240 (Anti-AI Jumps 240)

**СКАЧКИ·240** — это динамичная 3D-игра про конные скачки с препятствиями (стипль-чез), написанная на чистом HTML5, CSS3 и JavaScript с использованием библиотеки Three.js. 

Проект разработан как часть инициативы **Anti-AI Shield**: это бесплатное, полностью офлайн-приложение, которое не содержит рекламы, аналитических трекеров, скрытых скриптов или сбора персональных данных. Игра уважает ваше устройство, ваше время и вашу приватность.

## 🌟 Особенности

- 🎮 **Полноценная 3D-графика**: динамические тени, инстансинг объектов (деревья, зрители), процедурные текстуры, генерируемые через Canvas API.
- 📱 **Mobile-First**: идеальная работа на смартфонах (iOS/Android) благодаря оптимизированным обработчикам `touch`, отключению зума и плавной анимации.
- 🗣 **Голосовое сопровождение**: использование Web Speech API для озвучки старта, препятствий и результатов гонки на русском языке (с умной очередью и защитой от зависаний).
- 🧠 **Адаптивный ИИ соперников**: с каждой новой гонкой противники становятся немного быстрее, а режим «СЛОЖНЫЙ ×2» удваивает их скорость.
- 🔋 **Офлайн-готовность**: после первой загрузки (или при сохранении файла) игра работает без подключения к интернету.

## 🕹 Как играть

| Действие | Клавиатура (ПК) | Сенсорный экран (Мобильные) |
| :--- | :--- | :--- |
| **Ускорение (Галоп)** | `Пробел` (многократное нажатие) | Тап по любой свободной области экрана |
| **Прыжок через барьер** | `Стрелка вверх` ↑ или `W` | Кнопка «ПРЫЖОК» на экране |
| **Звук вкл/выкл** | Кнопка 🔊 в правом верхнем углу | Кнопка 🔊 в правом верхнем углу |

> 💡 **Совет:** Сбивание барьера приводит к потере скорости и анимации спотыкания. Рассчитывайте прыжок заранее!

## 🛠 Технологии под капотом

- **Рендеринг**: [Three.js](https://threejs.org/) (r128)
- **Аудио**: Web Audio API (процедурная генерация звуков копыт, ударов и сигналов без внешних mp3-файлов)
- **Речь**: Web Speech API (`SpeechSynthesis`) с кастомной системой очереди и таймаутами для максимальной стабильности в Chrome/Safari.
- **Стили**: Современный CSS с использованием переменных (`:root`), `clamp()` для адаптивной типографики и `backdrop-filter`.
